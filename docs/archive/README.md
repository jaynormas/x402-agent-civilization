# Archived documents

These files are from the 2025 "Good Morning City" / Solana x402 hackathon period of this repository. They are kept so that history is readable in the tree. **They are not the current Sun House plan.**

The current plan is in the [root README](../../README.md): a Sun House game set in The Server World, built in the open in Godot, Apple / iPhone first, and crypto-free in v1.

## What changed

- The project is now framed as **Sun House**, Jason Morland's independent media company, and its label **gM Records.** (the period is part of the name), building a game in the open.
- The earlier "Good Morning City" civilization framing, the **60/30/5/5** revenue split, Play Solana / PSG1 as the platform, and any $GM buyback language are historical.
- Claims in these files that x402 payments, ERC-8004 identity, treasuries, or city infrastructure were already live should be read as hackathon-era writing. The Solana program left in `programs/bridge` is a stub and is not used by the game.
